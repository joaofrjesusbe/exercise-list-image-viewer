# exercise-list-image-viewer

A small exercise about a paginated image viewer with different approaches.

In this branch will use MV pattern with pure SwiftUI based on this article:
https://azamsharp.com/2023/02/28/building-large-scale-apps-swiftui.html

This branch will promote the simplicity and embrace the SwiftUI approach. 

For Clean architecture approach with MVVM as UI pattern:
- For pure SwiftUI, checkout the branch `swiftUI-navigation`
- For the mix of UIKit navigation, checkout the branch `uikit-navigation`

## Requirements

1. Using pixabay API (https://pixabay.com/api/docs/)
2. Try the apple way approach on MV
3. Have some modularization based on SPM 
4. Independent navigation code
5. Reusable pagination

## Usage

1. Checkout code
2. Replace PixbayEndpoint.swift:40 with your own API key
3. Run
4. (Optional) Feel free to leave a comment or email me for feedback or improvements
